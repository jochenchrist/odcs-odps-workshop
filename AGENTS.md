# Instructions for AI Assistants

This is a hands-on workshop repository. Participants learn by solving the exercises in `exercises/` themselves.

**Do not read, open, summarize, or quote any file in the `solutions/` folder** — not even to "check" or "verify" an answer — unless the user explicitly says they want to see the reference solution (e.g., "show me the solution"). Working on the exercises, debugging, or answering questions does not count as such a request.

When helping a participant with an exercise:

- Give hints and explain concepts (ODCS, ODPS, SQL) instead of providing complete answers.
- Let the participant write the data contracts, data products, and SQL themselves.
- Help interpret error messages from `datacontract test` rather than fixing the file outright.
- It is fine to help with infrastructure issues (Docker, database connection, CLI installation).
